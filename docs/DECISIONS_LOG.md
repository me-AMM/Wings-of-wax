# Decisions log (builder: one line per choice you made where a doc was ambiguous or an asset was missing)

- M0: export preset excludes docs/ and tools/ from the pck; thread support off (itch.io friendly); screens use `.tscn` text files written by hand.
- docs/ has a .gdignore so Godot does not import the docs CSV as a translation.
- Water: drinking/watering removes only the NET loss at once (2.5 or 1.0 L x (1 - recycler return)), using the slider at that moment.
- Oxygen and power run continuously per game hour (rate/24 per hour); shadow days follow config shadow_days.
- Research uses the science slider value stored per day (science_hist); day 4 mission locks 15%, day 12 and 28 lock 12.5%.
- Storm warning is checked every step against the CURRENT storm watch slider (warning start = hit time minus warning length).
- JSON numbers are floats in GDScript: `int in [floats]` is false, so compare with float(day).
- day_snapshots.json holds the state at the START of each day (Judge jump loads it, then rebuilds today's queue).
- Packs on a sunny day: the policy swaps so the fuller pack runs the base (emptier one charges).
- M2: main scene temporarily = Outpost (M5 restores Title). Outpost.tscn generated by tools/make_outpost.py; edit in the editor afterwards.
- M3: abort = Esc menu or E at the base; keeping samples only if the waypoint (or stone) was reached. Storm during a mission ends it when the player is in the base zone. Greenhouse opens day 2 (rulebook), as built.
- M4: DONKI downloaded OK (5 M-class on 3-7 May 2024, X5.8 and X9.0 confirmed); large storm unsheltered = today's samples lost, finale unsheltered = failed ending.
- Judge: autoload Judge + JudgePanel; press J any time in Judge mode; presets 'storm in mission' (day 8) and 'big storm' (day 24) land the cargo and start the mission directly; main scene is Title again.
- PART 0: viewport is now 640x360 (x2 window). World coordinates unchanged, camera zoom 1. UI scripts keep their 320x180 layout inside CanvasLayers with scale 2 (integer, Nearest); world-space prompts use 12 px text. HUD icons are 32x32 box-downscaled copies in assets_derived/icons32 (resized by script, palette-snapped).
- PART 0B: player_speed (config player.player_speed) = 85 px/s. The brief asked for about 3.2x the old 55 (=176) but also a 15-20 s chore loop; 176 gives ~7 s, so the loop time wins (measured in collision_check). Walk animation speed_scale 1.5, dust puff every 96 px walked. Mission world is 1400x700 (waypoint and samples further apart), timers unchanged.
- PART 1: collision is real (StaticBody2D "Footprint" from sprite alpha, tools/footprints.py). collision_check.gd: 0 failures, every interaction point reachable. Chore loop measured by A* on a 4 px grid: 1137 px; player_speed set to 68 px/s = 16.7 s (inside the 15-20 s target).
- PART 2: greenhouse and tray are one unit (both kind "tray", one lock on the greenhouse).
- PART 3: font = Pixelify Sans (SIL OFL 1.1, Stefie Justprince, from google/fonts on GitHub; Monogram skipped, itch.io has no direct download). Import: antialiasing/hinting/subpixel off. Theme theme/game_theme.tres is the project theme. Credits line and fonts/LICENSE added.
- PART 4: HUD, storm banner, forecast board, title and Judge panel are drawn in real 640x360 pixels; menus/info cards are authored in 320x180 units inside 2x CanvasLayers with labels drawn at scale 0.5 so glyphs stay crisp. Not done: panels as StyleBoxTexture (NinePatchRect with the same margins is used), per-menu button width rule only on Title buttons.
- PART 5: Judge panel rewritten in real pixels (420x300), flat buttons, visible slider, J toggles.
- ui_check.gd, collision_check.gd and sim_check.gd all pass.
- BUGFIX ROUND (owner decisions, also in docs/02): finale flow rebuilt (crew lander hidden until the finale storm has passed while sheltered; lander drop animation, Extraction scene, EndingSuccess; not sheltered = EndingFailed). WAV import compress/mode = 0 (uncompressed) so the retro tones are exact. make_sfx.py rewritten to the spec (peak -3 dB, 8 s seamless loops). audio_check.gd added. M mute and the first-click unlock were fine (Title Start is a click/keypress).
